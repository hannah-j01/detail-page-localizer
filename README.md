# 상세페이지 현지화 도우미 (MVP)

한국 셀러의 상품 정보를 해외 쇼핑몰용 상세페이지 초안으로 바꾸는 웹 서비스입니다.
단순 번역이 아니라 **확인된 사실 → 마케팅 전략 → 현지화 문구 → 위험 표현 검수** 순서로 진행하고,
모든 문구에 근거와 수정 이유를 함께 표시합니다. 기획 내용은 `PRODUCT_BRIEF.md` 를 참고하세요.

> 데모 상품 '결담(GYEOLDAM) 어성초 77 진정 토너'는 **가상 브랜드**입니다.

## 화면 흐름

| 단계 | 하는 일 | AI 사용 |
|---|---|---|
| ① 상품 정보 입력 | 필수 8개 + 선택 정보, 국가·쇼핑몰 선택, 기존 상세페이지 이미지·PDF·URL | - |
| ② 추출 결과 확인 | 확인된 사실(F1, F2 …), 이미지별 분석(이미지 속 한국어 문구, 문제점), 추가 확인 질문 | 1회 (이미지 포함) |
| ③ 마케팅 전략 선택 | 추천 이유·근거·검증 지표를 보고 전략 선택 | 1회 |
| ④ 생성 결과 검수 | 원본과 수정안 비교, 역번역 확인, 수락·거절·직접 수정, 이미지별 수정 지시서 검토 | 1회 |
| ⑤ 내보내기 | 수락한 문구와 이미지 지시서를 Markdown / JSON 으로 다운로드, 작업 지표 기록 | - |

검수는 네 겹으로 합니다.
- **AI 자체 점검**: 생성 직후 AI가 스스로 찾은 위험 표현
- **규칙 검수**(무료): `config/risk_rules/` 의 패턴으로 원본(입력 텍스트 + 이미지 속 한국어 문구)과 현지화 문구(텍스트 + 이미지 교체 문구)를 검사. 직접 고친 문구도 즉시 다시 검사
- **근거 검수**(무료): 존재하지 않는 사실 ID, 증빙 없는 주장을 근거로 쓴 문구·이미지 지시서를 찾음
- **숫자 검수**(무료): 결과물의 '숫자+단위'(함량, 용량, 기간, 가격)가 입력 자료에 **같은 값·같은 단위**로 있는지 대조
  - '36개월'·'36ヶ月'·'36 months', '200ml'·'２００ｍｌ', 'pH 5.5'·'pH5.5' 를 같은 값으로 인식
  - 입력의 '두 병째' 같은 한국어 숫자 단어도 숫자로 바꿔 대조
  - 같은 숫자가 다른 단위로만 있으면 그 단위를 함께 알려 줌(예: 결과물 '36일' ↔ 입력 '36개월')
  - 순서 번호(STEP 1)와 '1本お試し' 같은 수량 1은 제외
  - 단위 목록은 `config/units.yaml` 에서 추가·수정

## 기존 상세페이지 넣는 방법

| 방법 | 설명 | 주의 |
|---|---|---|
| 이미지 업로드 | 상세페이지 이미지 여러 장. 세로로 긴 이미지는 **글자 사이 빈 줄을 찾아** 자동으로 나눔 | 상품당 최대 24조각 |
| PDF 업로드 | 10쪽 이하. 각 쪽을 이미지로 바꿔 같은 방식으로 분석 | 암호 걸린 PDF 불가 |
| URL 가져오기 | 페이지 텍스트와 상세 이미지를 가져옴. 가져온 이미지 중 분석에 넣을 것을 고를 수 있음 | 실제 AI 모드에서만 사용 |

URL 가져오기의 한계와 안전장치
- 셀러 본인의 상품 페이지용입니다. 사이트의 robots.txt 가 수집을 금지하면 접속하지 않습니다.
- 쿠팡(자동 접속 차단), 네이버 스마트스토어(robots.txt 금지)는 가져올 수 없습니다. 이때는 브라우저에서 `Ctrl+P → PDF로 저장` 후 PDF 로 올리면 됩니다.
- 서버가 입력된 주소에 접속하는 기능이므로 내부망·로컬 주소 접속을 막고, 리다이렉트마다 주소를 다시 검사하며, 크기(HTML 3MB, 이미지 8MB)와 시간(10초) 제한을 둡니다.
- 자바스크립트로 화면을 그리는 페이지를 위한 브라우저 자동화(Playwright 등)는 쓰지 않았습니다. 설치·배포가 무겁고, 막아 둔 사이트를 우회하는 용도가 되기 쉽기 때문입니다.

이미지 비용: 이미지 조각 하나는 약 1,600 토큰입니다. 이미지는 ②단계에서 한 번만 보내고, ④단계에는 ②의 분석 결과(텍스트)만 넘겨 같은 이미지에 두 번 비용을 내지 않습니다.

## 실행 방법 (Windows)

처음 한 번만:
```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

실행:
```powershell
.venv\Scripts\streamlit run app.py
```
브라우저에서 http://localhost:8501 이 열립니다. 종료는 터미널에서 `Ctrl + C`.

테스트(API 비용 없음):
```powershell
.venv\Scripts\python -m pytest -q
```

## 데모 모드와 실제 AI 모드

| | 데모 모드 | 실제 AI 모드 |
|---|---|---|
| 조건 | API 키가 없을 때 기본값 | `.env` 에 `ANTHROPIC_API_KEY` 를 넣었을 때 사이드바에서 선택 |
| 결과 | `demo/` 폴더에 저장된 예시 결과 | Claude API 가 실제로 분석·생성 |
| 비용 | 0원 | 상품 1개당 약 $0.3~1 (모델에 따라 다름, 사이드바에 표시) |

실제 AI 모드를 쓰려면 `.env.example` 을 복사해 `.env` 로 이름을 바꾸고 키를 넣으세요.
비용 보호 장치:
- `APP_PASSWORD`: 비밀번호를 아는 사람만 실제 AI 모드 사용
- `LIVE_CALL_LIMIT`: 한 세션당 최대 AI 호출 수(기본 9회 = 상품 3개)
- Anthropic Console 에서 **월 사용 한도**도 함께 설정하는 것을 권장합니다.

## 수정 방법

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| 새 국가 추가 | `config/countries/` 에 YAML 추가 |
| 새 쇼핑몰 추가 | `config/marketplaces/` 에 YAML 추가 (`country` 에 국가 id) |
| 새 카테고리 | `config/categories/` 에 YAML 추가 |
| 마케팅 전략 | `config/strategies/` |
| 위험 표현 목록 | `config/risk_rules/` (`pattern` 은 정규식) |
| 숫자 검수 단위 | `config/units.yaml` |
| AI 지시문 | `prompts/*.md` (한국어로 작성됨) |
| 데모 결과 | `demo/*.json` |

설정의 `verified: false` 는 '확인되지 않은 가설·규칙'이라는 뜻이고, 화면에 `미확인`/`미검증 가설` 로 표시됩니다.
실제 쇼핑몰 가이드나 법규를 확인했다면 `verified: true` 와 `source`, `reviewed_at` 을 갱신하세요.

## 폴더 구조

```
app.py               화면(Streamlit)
core/
  schemas.py         데이터 구조(AI 응답 형식)
  pipeline.py        추출 → 전략 → 생성 (데모/실제 전환)
  llm.py             Claude API 호출, 비용 계산
  media.py           이미지 조각내기, PDF → 이미지
  url_import.py      URL 가져오기(안전장치 포함)
  review.py          규칙·근거·숫자 검수
  export.py          Markdown/JSON 내보내기, 작업 지표
  config_loader.py   YAML 설정 읽기
config/              국가·쇼핑몰·카테고리·전략·위험 표현 설정
prompts/             AI 지시문
demo/                데모용 예시 입력·상세 이미지·결과 (make_demo_image.py 로 이미지 재생성)
tests/               자동 테스트
```

## 포트폴리오 배포 (Streamlit Community Cloud, 무료)

1. GitHub 에 저장소를 만들고 이 폴더를 올립니다(`.env` 는 자동으로 제외됨).
2. https://share.streamlit.io 에서 GitHub 로 로그인 → New app → 저장소와 `app.py` 선택 → Deploy.
3. **API 키를 넣지 않으면 데모 모드로만 동작해 비용이 0원**입니다. 포트폴리오 공개용으로 권장합니다.
4. 면접 등에서 실제 AI 를 시연하려면 앱 설정의 Secrets 에 아래처럼 넣습니다.
   ```toml
   ANTHROPIC_API_KEY = "..."
   APP_PASSWORD = "..."
   LIVE_CALL_LIMIT = "6"
   ```

## 한계와 다음 단계

- 이미지 자체를 자동으로 고치지는 않습니다(기획서 방침). 대신 디자이너용 수정 지시서와 '바꾸면 안 되는 요소' 목록을 만듭니다.
- 이미지 지시서는 화면에서 직접 고칠 수 있지만(문구 표·수정 지시·바꾸면 안 되는 요소), 고친 문구의 역번역은 자동으로 다시 만들지 않습니다('역번역 없음'으로 표시).
- 숫자 검수는 값과 단위가 같은지만 봅니다. 같은 단위의 같은 숫자가 다른 맥락에 쓰인 경우(예: 입력의 '판테놀 5%'를 결과물에서 '어성초 5%'로 잘못 옮김)는 잡지 못하므로, 성분별 수치는 사람이 한 번 더 확인해야 합니다.
- 단위 없는 숫자(예: 'ドクダミ77')는 값만 비교합니다.
- 위험 표현 목록과 쇼핑몰 규칙은 법률·정책 검토를 거치지 않은 초안입니다.
- 일본어 문구는 원어민 검수를 거치지 않았습니다.
