## 다듬는 기준
1. 번역투: 한국어 어순·조사를 그대로 옮긴 문장, 한국어 관용구의 직역, 지나치게 긴 수식 구조를 현지 표현으로 바꿉니다.
2. 톤과 경어: 국가 설정의 writing_style 과 쇼핑몰의 buyer_context 에 맞는 말투·경어 수준으로 모든 항목을 통일합니다. 입력에 '유지하고 싶은 말투·표현'이 있으면 따릅니다.
3. 쇼핑몰 관행: 상품명·핵심 소구점·CTA·검색 키워드는 {{marketplace_name}}의 상위 상품 페이지에서 흔히 쓰는 구성·어순·길이로 맞춥니다. 확인되지 않은(verified: false) 글자 수 제한은 강제하지 않습니다.
4. 표기: 숫자·단위·통화·날짜·고유명사(성분명, 브랜드명) 표기를 현지 관행에 맞춥니다. 값 자체는 바꾸지 않습니다.
5. 용어 일관성: 같은 성분·기능·제품명은 모든 항목과 이미지 문구에서 같은 표현을 씁니다.

## 바꾸면 안 되는 것
- 사실·수치·효능 범위: 뜻을 더하거나 더 강하게 만들지 않습니다. 새 주장·숫자·효능을 만들지 않습니다.
- 위험 표현 규칙에 걸리는 표현을 새로 넣지 않습니다.
- id, section, image_id, action, fact_ids, strategy_ids, is_ai_suggestion, original_ko 는 그대로 둡니다.

## 응답 규칙
- 실제로 고친 항목만 items / image_guides 에 넣습니다. 고친 항목은 다른 필드를 그대로 복사하고 localized, back_translation_ko, variants(이미지 지시서는 text_replacements 의 localized, back_translation_ko)만 바꿉니다. reason 끝에 '현지어 다듬기: …' 를 덧붙입니다.
- notes 에 항목 ID 와 함께 무엇을 왜 바꿨는지 한국어 한 줄씩 적습니다. 예: "S3: '〜することができます' → '〜できます' 로 간결하게".
- 다듬다가 발견한 위험(근거가 약한 표현 등)은 remaining_flags 에 적습니다. 없으면 빈 배열입니다.
