생성한 {{language_name}} 상세페이지 초안 가운데 코드 검수(위험 표현 규칙·근거·숫자)와 AI 자체 점검에 걸린 항목만 다시 씁니다.

## 작업 규칙
1. 아래 '검수에 걸린 문구'와 '검수에 걸린 이미지 지시서'만 고쳐서 돌려줍니다. id·section·image_id 는 그대로 두고, 목록에 없는 항목은 만들지 않습니다.
2. 각 항목의 검수_표시 를 source 별로 다음과 같이 해결합니다.
   - 규칙: 걸린 표현을 허용 범위의 표현으로 바꿉니다. 같은 뜻의 다른 금지 표현으로 바꾸지 않습니다.
   - 숫자: 사실 목록에 있는 값과 단위로 고칩니다. 사실 목록에 없는 숫자는 문구에서 뺍니다.
   - 근거: 존재하지 않는 사실 ID 는 지우고, 실제 근거가 있으면 그 ID 로 바꿉니다. 근거가 전혀 없는 사실형 문구는 is_ai_suggestion 을 true 로 하거나 사실 주장을 뺍니다. needs_evidence 가 true 인 사실에 기댄 주장은 문구에서 뺍니다.
   - 형식: 표시된 한도 이하로 줄입니다. 브랜드명 → 핵심 키워드 → 용량 순으로 남기고 수식어부터 뺍니다. 줄인 뒤 글자 수를 세어 확인합니다.
   - AI: 생성 때 스스로 표시한 위험입니다. 문구를 바꿔 해결할 수 있으면 바꿉니다. 동의·정책·증빙 확인처럼 사람이 해야 할 일이면 문구는 그대로 두고 remaining_flags 에 그대로 넣습니다.
3. 고친 문구는 localized, back_translation_ko, variants 를 함께 고치고, reason 끝에 '자기검수에서 수정: …' 를 덧붙입니다.
4. 이미지 지시서는 text_replacements 의 localized 와 back_translation_ko 를 고칩니다. 지울 문구는 localized 를 빈 문자열로 둡니다.
5. remaining_flags 에는 문구를 고쳐도 남는 위험과 사람이 확인해야 하는 사항만 적습니다. 해결한 표시는 적지 않습니다.
6. notes 에는 항목 ID 와 함께 무엇을 왜 고쳤는지 한국어 한 줄씩 적습니다.
7. 새 사실·숫자·효능을 만들지 않습니다. 국가 설정의 writing_style 을 유지합니다.
